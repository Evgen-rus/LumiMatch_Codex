# Reference

## Contact_harvester

Repository:
https://github.com/Evgen-rus/Contact_harvester

Использовать как архитектурный референс для:
- HTTP-first обхода;
- browser fallback;
- collector/extractor/service separation;
- retry и page limits;
- Playwright;
- устойчивости к ошибке одного домена;
- тестируемости.

Не переносить предметную телефонную логику.
