# WORKFLOW.md — как пользоваться после MVP

Целевой сценарий для каждого нового проекта:

1. Создать папку `projects/<имя_проекта>/`.
2. Положить туда технический PDF и визуализации.
3. Открыть LumiMatch в Codex.
4. Написать:

   `Обработай новый проект в projects/<имя_проекта> по правилам AGENTS.md. Используй текущий локальный каталог, при необходимости обнови его, затем сделай подбор и сохрани результат в output/<имя_проекта>.`

5. Codex:
   - читает PDF;
   - формирует/проверяет FixtureRequirement;
   - использует локальный каталог;
   - формирует shortlist;
   - визуально проверяет кандидатов;
   - выдаёт итоговую подборку.

6. Пользователь вручную проверяет финальные 3–5 вариантов на позицию.

Главная метрика: вместо долгого ручного обхода сайтов человек проверяет уже готовый shortlist.
