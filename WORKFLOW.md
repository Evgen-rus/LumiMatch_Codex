# WORKFLOW.md - как пользоваться LumiMatch V2

Целевой сценарий для каждого нового проекта:

1. Создать `projects/<имя_проекта>/` и положить туда технический PDF и визуализации.
2. Открыть LumiMatch в Codex и попросить обработать проект по `AGENTS.md`.
3. Codex проверяет весь проект и формирует `FixtureRequirement`, не теряя visual-only позиции. Для sample coverage mapping включает люстры/подвесы, линейный свет, бра, споты/трек, зеркало, profile/LED strip и track rail.
4. При необходимости обновить локальный каталог по всем доменам из `suppliers.txt`. Discovery сначала классифицирует product URLs из sitemap, затем bounded HTTP-fetches карточки. Один недоступный домен не останавливает остальные.
5. Извлечение сохраняет исходный текст наличия, конечный `availability_status`, taxonomy family, нормализованные размеры в миллиметрах и фотографии текущего SKU.
6. Перед визуальным просмотром выполняются hard gates: capability-aware availability (`stock_tracked` требует `in_stock`; `stock_not_published` допускает отсутствие статуса без явных негативных маркеров), совместимая family, критический монтаж/техника/размеры и пригодное фото.
7. Для каждого требования строится широкий pool примерно 30-100 карточек и `output/review/<id>/sheet_*.jpg`. Codex смотрит reference crop и sheets, фиксирует accept/reject в `data/visual_review.json`.
8. После visual reject остаётся от 0 до 5 финалистов. Цветовой fallback запускается только если хороший кандидат требуемого цвета не прошёл; он помечается `color_alternative`.
9. Каждый финалист повторно проверяется по публичной карточке поставщика без кэша. Для `stock_tracked` нужна актуальная `in_stock`; для `stock_not_published` проверяются URL, SKU и отсутствие явного negative marker.
10. Результаты сохраняются в `output/`: HTML, Markdown, JSON, crops, contact sheets и `debug/rejected_candidates.json`. Для следующего проекта нужно обновить только его requirements/review, не смешивать старый feedback с новым.

Главная метрика: продавец получает короткий визуально проверенный список доступных моделей или честное `Ничего не найдено. Попробуйте подобрать вручную.`. Автоматический score не является доказательством визуального совпадения.
